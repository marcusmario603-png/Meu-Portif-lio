# Portfólio Profissional - Marcus Mário | Analista de Dados

## 🌐 Visão Geral

Este repositório contém a estrutura base (`index_2.html`) do portfólio digital de **Marcus Mário**, Analista de Dados Júnior e estudante de Análise e Desenvolvimento de Sistemas (ADS). 

O projeto consiste em uma página web (Landing Page/Single Page Application) com design moderno e focado em tecnologia (inspirado em interfaces de terminal e editores de código), projetada para apresentar o perfil profissional do desenvolvedor, suas habilidades técnicas e seu catálogo de projetos.

## 🎯 Objetivo do Arquivo

O arquivo `index_2.html` foi criado para servir como um **currículo interativo e dinâmico** e uma **vitrine de projetos**. Seu propósito exato é centralizar a presença digital do analista, permitindo que recrutadores, empresas e parceiros de negócios possam:
1. Compreender rapidamente o foco de atuação do profissional (Business Intelligence, Automação, Transformação de Dados).
2. Avaliar as competências técnicas e ferramentas dominadas.
3. Acessar links diretos para dashboards e repositórios de projetos reais (como Power BI, Python, Excel).
4. Entrar em contato direto de forma facilitada.

## 🏗️ Estrutura da Aplicação

O arquivo HTML está semântica e logicamente dividido nas seguintes sessões:

* **Nav (Navegação):** Menu superior interativo e responsivo para fácil rolagem pela página.
* **`#inicio` (Hero Section):** Apresentação de alto impacto contendo o cargo, proposta de valor e botões de chamada para ação (Call to Action).
* **`#sobre` (About):** Resumo biográfico, métricas de carreira (ex: "10+ dashboards construídos") e um painel estilo "terminal" detalhando as **Ferramentas e Tecnologias** dominadas (Python, SQL, Power BI, Excel, HTML, Claude, Bancos de Dados).
* **`#projetos` (Portfolio):** Grade de cartões de projetos contendo o contexto das análises desenvolvidas, tecnologias aplicadas e links para os resultados (ex: Dashboards Tech.Store e GeP).
* **`#contato` (Contact):** Painel de conexões integradas com links diretos para E-mail, LinkedIn, GitHub e WhatsApp, informando SLA de resposta (disponibilidade).

## 💻 Tecnologias e Dependências

A estrutura foi montada utilizando as seguintes tecnologias front-end:

* **HTML5:** Para a marcação e estruturação semântica do conteúdo.
* **Google Fonts:** Utilização das fontes `JetBrains Mono` (para dar um aspecto técnico e de código) e `Inter` (para legibilidade dos textos principais).

**Dependências Externas:**
Para que o arquivo `index_2.html` seja renderizado corretamente com todo o seu design e interatividade, ele depende dos seguintes arquivos localizados no mesmo diretório:
* `styles.css`: Arquivo responsável pela estilização, layout (grids), cores e efeitos visuais (como o `.bg-glow` e `.tunnel-fx`).
* `script.js`: Arquivo responsável pela interatividade, animações de scroll e comportamento do menu de navegação.

## 🚀 Como Executar Localmente

1. Faça o clone deste repositório ou o download dos arquivos.
2. Certifique-se de que os arquivos `index_2.html`, `styles.css` e `script.js` estejam na mesma pasta.
3. Dê um duplo clique no arquivo `index_2.html` para abri-lo diretamente em seu navegador web preferido (Google Chrome, Firefox, Edge, etc.).
4. (Opcional) Para desenvolvimento, recomenda-se a utilização da extensão "Live Server" no VS Code para auto-recarregamento da página a cada salvamento.
